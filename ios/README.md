# 관제 스케줄러 — iOS

안드로이드판과 같은 근무표를 그리는 SwiftUI 앱입니다.

## 먼저 알아 두실 것

**이 코드는 아직 한 번도 빌드된 적이 없습니다.** iOS 앱은 macOS 와 Xcode 에서만
컴파일할 수 있는데, 이 저장소는 Windows 에서 작업했습니다. 따라서 첫 빌드에서
자잘한 컴파일 오류가 나올 수 있습니다. 로직은 안드로이드판에서 실기기 검증을
마친 것을 옮겼지만, 화면 코드는 눈으로 확인하지 못했습니다.

## 빌드

맥과 Xcode 16 이상이 필요합니다.

```bash
brew install xcodegen        # 처음 한 번만
cd ios
xcodegen generate
open SocScheduler.xcodeproj
```

Xcode 에서 두 타깃(`SocScheduler`, `SocSchedulerWidget`) 모두

1. **Signing & Capabilities** 에서 본인 Apple 계정(팀)을 고르고
2. **App Groups** 에 `group.com.soc.scheduler` 가 켜져 있는지 확인

한 뒤 아이폰을 연결해 실행합니다. 무료 계정으로도 설치되지만 7일마다 다시
설치해야 합니다. 유료 개발자 계정(연 $99)이면 1년입니다.

XcodeGen 을 쓰기 싫으면, Xcode 에서 새 iOS App 프로젝트를 만들고 `SocScheduler`
폴더를 통째로 끌어다 넣은 뒤 Widget Extension 타깃을 하나 추가해도 됩니다.

## 안드로이드판과 같은 것

- 교대 패턴 5종과 직접 설정, 근무 시작일 기준 사이클 계산 (`ShiftEngine`)
- 시작일 이전 구간은 평일 주간 · 주말 휴무로 채움
- 근무 직접 변경, 야간 지정 시 다음 날 비번 함께 변경
- 현재 패턴에 쓰이지 않는 근무는 접어 두기 (4조 2교대에서 "오후" 숨김)
- 일정 · 할 일, 정기 점검 체크리스트
- 근무 유형별 기상 알람 (주간 07:30 / 야간 16:00 기본, 비번 · 휴무는 없음)
- 아침 근무 알림
- 화면 테마 (기기 설정 / 밝게 / 어둡게)
- 홈 화면 위젯

`ShiftEngine.swift` 는 `ShiftEngine.kt` 와 같은 규칙을 따릅니다. 두 앱이 같은
근무표를 그려야 하므로 한쪽을 고치면 다른 쪽도 고쳐야 합니다.

## 다른 것

### 알람

**iOS 는 앱이 시스템 알람을 만들 수 없습니다.** 안드로이드판은
`AlarmManager.setAlarmClock()` 으로 잠금화면 위에 전체화면을 띄우고 무음 모드를
뚫고 소리를 냅니다. iOS 에서 그렇게 할 수 있는 것은 애플의 시계 앱뿐입니다.

그래서 여기서는 알림(Notification)으로 만들었습니다.

- 소리는 길어야 30초. 끌 때까지 계속 울리지 않습니다.
- 무음 스위치를 올려 두면 소리가 나지 않습니다.
- 집중 모드는 `interruptionLevel = .timeSensitive` 로 뚫습니다. 설정에서 이 앱의
  "시간 민감" 알림을 허용해 두셔야 합니다.
- 무음까지 뚫으려면 Critical Alerts 권한이 필요한데 애플에 따로 신청해
  승인받아야 합니다. 개인용 앱은 대체로 받기 어렵습니다.

즉 이 앱의 알람은 **확실히 깨워 주는 알람이 아니라 그 시각에 눈에 띄게 알려 주는
알림**입니다. 놓치면 안 되는 날은 시계 앱 알람과 함께 쓰시길 권합니다.

### 위젯

안드로이드판은 위젯이 넷(오늘 근무 · 이번 주 · 월간 · 오늘 할 일)이지만, iOS 는
같은 위젯이 크기별로 모습을 바꾸는 쪽이 관례라 하나로 합쳤습니다. small 은 오늘
근무, medium 은 이번 주입니다.

위젯에서 점검 항목을 바로 체크하는 기능은 아직 없습니다. iOS 17 의
App Intent 로 넣을 수 있습니다.

### 아직 없는 것

- **친구 근무표 공유** — Supabase 로그인, 초대 코드, 수락제. 안드로이드판에는
  있습니다. iOS 에 넣으려면 `supabase-swift` 패키지와 OAuth 리디렉션 설정이
  필요해서 다음으로 미뤘습니다.
- 근무 시간 직접 수정 화면 (설정에서 보기만 됩니다)
- 교대 패턴 세부 조정 (기준일 · 내 조 직접 지정)

## 자료 저장

기기 안 SwiftData 한 곳에만 저장하며 밖으로 나가지 않습니다. 앱과 위젯이 같은
파일을 봐야 해서 App Group 컨테이너에 둡니다. App Group 설정이 빠지면 앱은
동작하지만 위젯이 비어 보입니다.
